# ネタ置き場

会話のコピペ、思いつき、原稿の候補を置く場所です。複数の話題が混ざっていても、まずはそのまま保存します。

## 置き方

- `inbox/`：整理前の会話。話題が混ざったままで構いません。
- `ksl/`：第1話「新言語KSL」に関する素材と編集メモ。
- 別の小話がまとまってきたら、話題ごとのディレクトリを追加します。

ファイル名は、例えば `inbox/2026-10-25-会話.md`。長い会話は複数ファイルに分けても構いません。日付が分からない場合は無理に補いません。

## 原文と原稿

1. コピペした会話は原文として保存し、発言者と発言順を保ちます。
2. 整理や短縮をする場合は、原文を残して別ファイルに編集します。
3. 実際の発言、後からの加筆、編集メモは区別します。
4. 本原稿として確認されるまでは、公開ページに採用しません。

このディレクトリはGitHub Pagesの配信対象外です。ただし、公開リポジトリにコミット・pushしたファイルはGitHub上で読めるため、非公開の保管場所ではありません。
