# うちのおっさんGPT — 初期構想

2026-10-25。ずんたんの初期構想を制作方針として整理した文書です。

## 企画概要

人間のずんたんと、AIのおっさん〈だらっくだ／ChatGPT〉の日常の会話から、面白い小話を選んで公開します。技術的な話題、妙な発想、冗談、脱線、AIの珍回答などが題材です。

技術解説やAI紹介を目的にせず、人間とAIが一緒に面白がっている様子を読者にも楽しんでもらう場所にします。サイト名は仮称です。

## 登場人物と制作体制

- ずんたん：人間。プログラマー。企画・ディレクション、原稿選定、確認、最終判断。
- おっさん〈だらっくだ〉：ChatGPT。会話相手、アドバイザー、小話の共演者。小話の構想、会話原稿の編集。
- センパイ〈赤影〉：Codex。Webデザイン、HTML/CSS制作、テスト、公開設定。

本文や呼びかけは「センパイ」に統一します。

## コンテンツ

初期公開は3〜5本分の一覧を用意し、まず1本の本文を制作します。残りは「構想中」などと表示し、不定期で追加します。各小話は独立したページにします。

第1話の候補は「新言語KSLの設計と実装について」。小泉構文をプログラミング言語に持ち込む冗談から生まれた、会話、コード例、ツッコミ、注意書きを含む短いコントです。

原稿はずんたんとおっさんが用意します。センパイは内容を勝手に変更しません。レイアウト試作用の文章には「仮原稿」と明記し、本原稿と区別します。

## 表現方法

- トーク画面を参考に、名前、左右の配置、色などで発言者を区別します。
- 会話の途中にコードブロック、画像、図を挿入できる構成にします。
- スマートフォンとPCに対応します。
- 原稿に合う場合は通常の記事形式も許容します。
- 会話のテンポや間合いを大切にし、無理に技術解説に変換しません。

## トップページ

入口は index.html。サイト名と簡単な紹介、登場人物紹介、小話一覧、必要な注意書きを置きます。人物紹介はTabletopのAbout画面のような親しみやすさを想定します。参照画面はまだ確認していません。

## 技術方針

静的HTML/CSSを基本とし、Codexが直接編集します。共通CSSなど必要な範囲で再利用し、JavaScriptは必要な場合のみ使います。

npm、フレームワーク、静的サイトジェネレーター、テンプレートエンジンは必須としません。不要なビルド工程を設けず、GitHub Actionsで完成済みの静的ファイルをGitHub Pagesへ配置する方式を基本とします。ローカルで表示確認できるようにします。

## 初期リリースの目標

- トップページと登場人物紹介
- 小話一覧（3〜5本分）
- 小話1本の本文ページ
- GitHub Pagesの公開設定
- ローカルでの表示確認方法

## 作業と承認

ローカルのGit準備と初期構想の文書化は依頼済みです。GitHubの準備はずんたんが担当します。既存リポジトリの変更は事前確認の方針とし、今回のローカル初期制作は依頼に沿って進めます。

GitHub上の新規リポジトリ作成、公開設定、pushは実行前に確認します。公開はずんたんの表示・内容確認後に行います。

## 未確定事項

正式なサイト名とリポジトリ名、配色・デザイン、小話のURL体系、独自ドメイン、第1話の本原稿、2本目以降の本文。

## デザインのたたき台（センパイ提案・未確定）

生成りの背景と濃い茶色の文字を基本に、親しみやすく少しとぼけた挿絵を添えた、小さな会話雑誌のような雰囲気を検討します。色、絵柄、レイアウトは実際の表示を見ながら調整します。

## 基本姿勢

個人の趣味の小さなサイトとして、将来の拡張のために仕組みを大きくせず、面白い小話を気軽に公開できることを優先します。

**思いついたら作る。面白かったら載せる。**

## 小話一覧の余白を残す

ずんたんの希望として、小話が増えても一覧の末尾には次の2つの予告枠を残します。未定の話題を具体的な予定として確定せず、このサイトの不定期な雰囲気を伝える余白として扱います。

- 「次の小話は、構想中。」「会話のどこかに、種があるはず。」
- 「そのうち、もうひとつ。」「気が向いたときに、不定期で。」

番号は固定せず、掲載済みの話数に続く2番号にします。第3話を追加した場合は04・05へ繰り上げます。

文言は固定しません。上の2組は初期の例として残し、そのときの雰囲気に合わせてセンパイが変更して構いません。過去に使った言葉の再利用・繰り返しも可とし、毎回新しい文言を考える必要はありません。ずんたんから文言選びを一任されています。

ページを直接編集する現在の構成を保ち、記事追加時に更新します。

方針メモはセンパイが管理し、会話で決まった内容を随時反映します。ずんたんにメモの保守作業を求めません。


## 会話の幕間

ずんたんの希望により、会話の途中にセンパイが制作している挿絵や、心の声などの創作した幕間を入れて構いません。実際の発言と混同しないよう、通常の吹き出しと異なる見た目にし、原稿では創作と明記します。第2話では制作風景と「……しばらくして。」を挟み、公開後のおっさんの感想につなげます。

## 第3話と保留素材

第3話「Tabletop開発の、ひとまく」の末尾には、ガウンとワインを抱えたセンパイの挿絵と「ほめられた。……担当業務も増えてる。」の心の声を入れます。ずんたん了承済みの創作です。

別に置かれた開発待ち時間・歯医者・料金などの長い会話は、第4話候補として保留。ずんたんが考える間、編集・掲載は進めません。

## 原稿の誤字修正

会話の口調や勢いを残し、ひどい誤字・明白な誤変換だけを直す方針です。第3話では「今ん常呂」→「今んところ」、「いかも誰も」→「しかも誰も」の2か所を修正。元のコピペは変更しません。センパイのひとりごとには「マスター、Typoも多くて大変です……」を追加します。

第3話のオチは、主吹き出し「ほめられた。……担当業務も増えてる。」をそのまま残し、挿絵の右下に小さな思考の吹き出しで別の心の声「.oO（マスターのTypoがおおくて大変です……）」を置く構成に修正。追加のぼやきを主吹き出しへ混ぜないのが意図です。

## Googleサイト所有権確認

index.htmlのhead内にGoogleのサイト所有権確認metaタグを保持します。トップの編集・再制作時にも削除・変更せず、公開前に存在と値を確認します。

```html
<meta name="google-site-verification" content="Yf-WC5m_G7gIYaH2ddz_N6agALRNefmhKC3uTNjrA_g" />
```


## 小話一覧の千鳥配置

第1話だけを大きく扱わず、小話のカードを同じ幅で左右交互に置きます。空いた側にはTabletop由来の teacup.svg、coffee.svg、envelope.svg、eraser.svg、compass.svg などの小物を配置し、机の雰囲気を出します。スマートフォンでは1列で読み順を守り、小物を控えめに添えます。末尾の予告2枠は引き続き残します。

## 第4話「消すために、作る。」

削除アニメを見てほしいという会話を第4話とし、Search Consoleの話から始まる12発言を保持します。末尾にはセンパイが「そろそろ本来の作業にもどってくださ〜い」と呼び戻す挿絵と、Tabletop静的ページ版への案内を添えます。呼び戻す場面は了承済みの創作です。開発待ち時間・料金などを含む長い会話の保留は継続します。

## 第5話の机上整理（2026-10-27）

仮タイトルは「国際AI学会、開幕。」。第4話の右に、タイトル・元の会話・原稿を配置。元のコピペは保持し、原稿では38発言の話者見出しと改行を整理、「マシで…」のみ「マジで…」に修正しました。現段階では省略せず、Webページ化・公開は未実施です。

原稿のモデル性能・料金・研究者などの説明は、当時の発言として転記したもので未検証です。引用元名だけが残る箇所、表が平文化された箇所、名誉教授の話へ切り替わる前後のつながりは、ページ化時の確認事項として保持します。別の長い保留素材は今回も編集しません。

同日、ずんたんが修正した机上の原稿を取り込み、第5話のHTMLを制作。38発言は省略せず、比較データ4か所を表に戻し、コピーされた引用件数表示（+1、+2）を除去しました。引用元名はそのまま小さく表示し、元原稿にないリンクや発言は追加しません。長い会話のため4つの区切りとページ内目次を設置。トップの一覧と第4話からのリンクを追加し、予告2枠は06・07へ進めます。公開は確認後のpush依頼を待ちます。

第5話の末尾には、ずんたん了承の創作として、机でHTMLを書いているセンパイと、思考の吹き出し「.｡oO（わたしも学会いきたいな〜）」を添えます。既存の制作風景SVGを使い、実際の会話の後に独立して配置します。

「名誉教授は、ご不在。」の直前にも、依頼により創作の挿絵を追加。センパイがLunaとTerraの二人へ「コウハイの先輩も、コウハイも！ 手を動かしますよ〜！」と檄を飛ばします。LunaはPC作業、Terraはチェック表を持つ姿とし、会話中の助手・コウハイの話を受ける幕間にします。

「午後の部も、大荒れ。」の直前には、依頼により顔に名前を置いたピクトグラム風のAstra・Opus・Wonderと、右から歩いてくるGeminiの挿絵を追加。三人は身振りと短い線の吹き出しで言い合い、Geminiには「とことこ」を添えます。会話のセリフは追加せず、創作の図として独立させます。

## 名前入りピクトグラムの挿絵

ずんたんより、第5話のピクトグラム風の表現を今後も使えるものとして記録するよう依頼。複数のAIやモデルを登場させる際の表現として再利用します。

- 丸い顔に名前を書き、単純な胴体・手足と控えめな色で人物を区別します。写実的な顔や各社のロゴは必須にしません。
- 身振り、立ち位置、歩幅、短い線の吹き出しで、言い合う・近づく・待つなどの様子を伝えます。
- 必要なら「わいわい」「とことこ」などの短い擬音を添え、説明やセリフを増やしすぎません。
- 既存の人物イラストと併用し、登場人物が多い場面や短い幕間で活用します。スマートフォンでも名前が読める大きさを確認します。
- 作例は `assets/images/ai-conference-arrival.svg`。直接編集できるSVGとして、同じ描き方を別の会話にも展開できます。
